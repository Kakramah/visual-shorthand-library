# مكتبة الاختصارات البصرية

مكتبة ويب عربية تفاعلية للاختصارات والمعادلات البصرية. التطبيق موجود في ملف HTML واحد ويُعرض عبر GitHub Pages.

**الموقع:** https://kakramah.github.io/visual-shorthand-library/

## بنية المشروع

- `index.html`: المحتوى والتصميم والتفاعل في ملف واحد.
- `.gitignore`: استثناء ملفات العمل المحلية من التتبع.

## المعاينة والتعديل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً من جذر المستودع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. بعد التعديل، اختبر البحث والتصفية والتفاعل إن مسستها، وافحص العرض على الهاتف والحاسوب. الخطوط المحمّلة من Google Fonts تحتاج اتصالاً بالشبكة. لا توجد خطوة بناء في جذر المستودع.
